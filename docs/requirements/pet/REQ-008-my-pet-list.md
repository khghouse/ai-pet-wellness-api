# REQ-008: 내 반려견 목록 조회

- **목표:** 인증된 회원은 현재 관리 권한이 있는 반려견 목록을 조회할 수 있다.
- **행위자:** JWT 인증된 회원
- **범위:** 현재 회원의 반려견 목록 조회
- **관련 엔티티:** `Pet`, `PetMembership`
- **제외 범위:**
  - 반려견 상세 조회
  - 반려견 정보 수정 및 삭제
  - 체중 이력 및 현재 체중 조회
  - 가족 구성원 초대 및 멤버십 수락
  - 반려견 검증

## API

- `GET /api/v1/pets`
- 성공 상태 코드: `200 OK`
- 페이지네이션: 미적용

## 응답값

응답은 반려견 목록 배열로 제공한다.

- `id`: 반려견 식별자
- `name`: 반려견 이름
- `birthDate`: 생년월일, `yyyy-MM-dd` 형식
- `membershipRole`: 현재 회원의 반려견 관계 역할, `OWNER` 또는 `FAMILY`

## 정책

- JWT 인증된 회원만 반려견 목록을 조회할 수 있다.
- 현재 회원의 `ACTIVE` 멤버십에 연결된 반려견만 조회한다.
- 삭제된 반려견은 목록에서 제외한다.
- `LEFT` 상태 멤버십에 연결된 반려견은 목록에서 제외한다.
- 목록은 최근 등록순으로 정렬한다. 반려견 `createdAt` 내림차순을 기본으로 하고, 동일한 등록일시에는 `id` 내림차순으로 정렬한다.
- 페이지네이션을 적용하지 않는다.
- 반려견 목록이 없으면 `200 OK`와 빈 배열을 응답한다.
- 목록 응답에는 체중, 견종, 성별, 중성화 상태, 생성일시, 수정일시를 포함하지 않는다.
- 나이는 현재 시각에 따라 변하는 파생값이므로 응답하지 않고, 원본값인 `birthDate`를 응답한다.

## 흐름

1. 인증된 회원이 내 반려견 목록 조회를 요청한다.
2. 시스템은 현재 회원의 `ACTIVE` 멤버십을 조회한다.
3. 시스템은 삭제되지 않은 연결 반려견만 식별한다.
4. 시스템은 최근 등록순으로 목록을 정렬한다.
5. 시스템은 반려견 요약 정보와 현재 회원의 멤버십 역할을 배열로 응답한다.

## 완료 기준

- [ ] 인증되지 않은 사용자는 반려견 목록을 조회할 수 없다.
- [ ] `ACTIVE` 상태의 `OWNER` 멤버십 반려견이 목록에 포함된다.
- [ ] `ACTIVE` 상태의 `FAMILY` 멤버십 반려견이 목록에 포함된다.
- [ ] 다른 회원에게만 연결된 `ACTIVE` 상태의 반려견은 목록에 포함되지 않는다.
- [ ] `LEFT` 상태 멤버십 반려견은 목록에 포함되지 않는다.
- [ ] 삭제된 반려견은 목록에 포함되지 않는다.
- [ ] 반려견 목록은 최근 등록순으로 정렬된다.
- [ ] 반려견이 없으면 `200 OK`와 빈 배열을 응답한다.
- [ ] 응답은 `id`, `name`, `birthDate`, `membershipRole`만 포함한다.
- [ ] 응답에 체중, 견종, 성별, 중성화 상태, 생성일시, 수정일시는 포함되지 않는다.

## 테스트 기준

- `OWNER` 멤버십 반려견 목록 조회 성공
- `FAMILY` 멤버십 반려견 목록 조회 성공
- 다른 회원의 `OWNER`, `FAMILY` 반려견 목록 제외 확인
- `LEFT` 멤버십 및 삭제된 반려견 목록 제외 확인
- 반려견 `createdAt` 내림차순, 동일 등록일시 `id` 내림차순 정렬 확인
- 반려견이 없는 회원의 빈 배열 응답 확인
- 미인증 사용자 조회 실패
- 응답 필드 범위 확인
