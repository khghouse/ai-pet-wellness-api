# REQ-010: 반려견 정보 수정

- **목표:** 인증된 소유자는 자신이 소유한 반려견의 기본 정보를 수정할 수 있다.
- **행위자:** JWT 인증된 `OWNER` 회원
- **범위:** 반려견 기본 프로필 전체 수정
- **관련 엔티티:** `Pet`, `Breed`, `PetMembership`, `PetWeight`
- **제외 범위:**
  - 체중 이력 생성, 수정, 삭제
  - 가족 구성원 초대 및 멤버십 역할 변경
  - 반려견 삭제
  - 반려견 검증
  - 산책, 미션, 리워드 기능

## API

- `PUT /api/v1/pets/{petId}`
- 성공 상태 코드: `200 OK`

## 입력값

### Path Variable

- `petId`: 반려견 식별자

### Request Body

- `name`: 반려견 이름, 필수
- `birthDate`: 생년월일, 필수, `yyyy-MM-dd` 형식
- `gender`: 성별, 필수, `MALE`, `FEMALE`, `UNKNOWN`
- `breedId`: 견종 식별자, 필수
- `neuteredStatus`: 중성화 상태, 필수, `NEUTERED`, `NOT_NEUTERED`, `UNKNOWN`

## 응답값

- `id`: 반려견 식별자
- `name`: 수정된 반려견 이름
- `birthDate`: 수정된 생년월일
- `gender`: 수정된 성별
- `breed`: 수정된 견종 정보
  - `id`: 견종 식별자
  - `name`: 견종명
- `neuteredStatus`: 수정된 중성화 상태
- `updatedAt`: 수정일시, ISO-8601 `LocalDateTime` 형식

## 정책

- JWT 인증된 회원만 반려견 정보를 수정할 수 있다.
- 존재하고 삭제되지 않은 반려견만 수정할 수 있다.
- 해당 반려견의 `ACTIVE` 상태 `OWNER` 멤버십을 가진 회원만 수정할 수 있다.
- `FAMILY`, `LEFT` 멤버십 회원 또는 관계없는 회원은 수정할 수 없다.
- 수정 요청은 이름, 생년월일, 성별, 견종, 중성화 상태를 모두 포함해야 한다.
- 생년월일은 미래 날짜일 수 없다.
- 생년월일은 기존 체중 이력 중 가장 이른 `measuredAt`의 날짜보다 미래로 변경할 수 없다.
- 현재 반려견에 연결된 비활성 견종은 수정 요청에서 그대로 유지할 수 있다.
- 현재 반려견과 다른 견종으로 변경할 때는 활성 상태 견종만 선택할 수 있다.
- 존재하지 않는 견종은 선택할 수 없다.
- 체중은 이 API에서 수정하지 않는다. 체중 변경은 별도 체중 이력 생성 API로만 처리한다.
- 수정 성공 시 수정된 반려견 정보만 응답하며, 체중과 멤버십 정보는 포함하지 않는다.

## 흐름

1. 인증된 회원이 반려견 식별자와 수정할 전체 프로필 정보를 입력한다.
2. 시스템은 필수값과 입력 형식을 검증한다.
3. 시스템은 반려견이 존재하고 삭제되지 않았는지 확인한다.
4. 시스템은 요청 회원이 해당 반려견의 `ACTIVE` 상태 `OWNER` 멤버십을 보유하는지 확인한다.
5. 시스템은 생년월일이 미래가 아니고 기존 체중 이력과 시간 정합성을 만족하는지 확인한다.
6. 시스템은 요청 견종이 현재 견종과 같은지 확인한다.
7. 견종이 변경되는 경우 시스템은 요청 견종이 존재하고 활성 상태인지 확인한다.
8. 시스템은 반려견 기본 정보를 수정한다.
9. 시스템은 수정된 반려견 정보를 응답한다.

## 완료 기준

- [ ] 인증되지 않은 사용자는 반려견 정보를 수정할 수 없다.
- [ ] 존재하지 않거나 삭제된 반려견은 수정할 수 없다.
- [ ] `ACTIVE` 상태의 `OWNER` 회원은 반려견 정보를 수정할 수 있다.
- [ ] `FAMILY`, `LEFT` 멤버십 회원 또는 관계없는 회원은 반려견 정보를 수정할 수 없다.
- [ ] 이름, 생년월일, 성별, 견종, 중성화 상태 중 하나라도 누락되면 수정에 실패한다.
- [ ] 생년월일 형식이 올바르지 않거나 미래 날짜이면 수정에 실패한다.
- [ ] 생년월일을 기존 체중 이력 중 가장 이른 측정일보다 미래로 변경하면 수정에 실패한다.
- [ ] 존재하지 않는 견종을 선택하면 수정에 실패한다.
- [ ] 현재 견종과 다른 비활성 견종으로 변경하면 수정에 실패한다.
- [ ] 현재 연결된 비활성 견종을 그대로 유지하는 수정은 성공한다.
- [ ] 체중은 수정되지 않고 기존 `PetWeight` 이력이 유지된다.
- [ ] 성공 응답은 `id`, `name`, `birthDate`, `gender`, `breed`, `neuteredStatus`, `updatedAt`만 포함한다.
- [ ] 성공 응답의 HTTP 상태 코드는 `200 OK`다.

## 예외

- 필수값 누락 또는 입력값 형식 오류
- 미래 생년월일 또는 기존 체중 이력과 시간 정합성이 맞지 않는 생년월일
- 반려견 없음 또는 삭제된 반려견
- `OWNER` 멤버십 없음 또는 종료된 멤버십
- 존재하지 않거나 변경 대상으로 사용할 수 없는 비활성 견종

## 테스트 기준

- `OWNER` 회원 반려견 정보 수정 성공
- 미인증 사용자 수정 실패
- `FAMILY`, `LEFT` 멤버십 회원 및 관계없는 회원 수정 실패
- 존재하지 않거나 삭제된 반려견 수정 실패
- 필수값 누락, 미래 생년월일, 유효하지 않은 성별 또는 중성화 상태 입력 실패
- 기존 체중 이력 중 가장 이른 측정일보다 미래인 생년월일 수정 실패
- 존재하지 않는 견종 및 변경 대상 비활성 견종 수정 실패
- 기존 비활성 견종을 유지하는 수정 성공
- 수정 후 체중 이력이 변경되지 않는지 확인
- 성공 응답 필드 범위와 `200 OK` 확인
