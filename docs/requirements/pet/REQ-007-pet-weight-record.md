# REQ-007: 반려견 체중 기록

- **목표:** 인증된 회원은 관리 권한이 있는 반려견의 체중을 측정 시각과 함께 기록할 수 있다.
- **행위자:** JWT 인증된 회원
- **범위:** 반려견 체중 이력 생성
- **관련 엔티티:** `Pet`, `PetWeight`, `PetMembership`
- **제외 범위:**
  - 체중 이력 수정 및 삭제
  - 체중 이력 목록 및 현재 체중 조회
  - 반려견 정보 수정 및 삭제
  - 반려견 검증
  - 산책, 미션, 리워드 기능

## API

- `POST /api/v1/pets/{petId}/weights`
- 성공 상태 코드: `200 OK`

## 입력값

### Path Variable

- `petId`: 반려견 식별자

### Request Body

- `weight`: 체중, kg 단위
- `measuredAt`: 실제 체중 측정 시각, ISO-8601 `LocalDateTime` 형식

## 응답값

- `id`: 생성된 체중 이력 식별자
- `weight`: 기록된 체중, kg 단위
- `measuredAt`: 실제 체중 측정 시각
- `createdAt`: 체중 이력 등록 시각

## 정책

- JWT 인증된 회원만 체중을 기록할 수 있다.
- 반려견이 존재하지 않거나 삭제된 상태이면 체중을 기록할 수 없다.
- 해당 반려견의 `ACTIVE` 멤버십을 가진 `OWNER`, `FAMILY` 회원만 체중을 기록할 수 있다.
- `LEFT` 상태 멤버십 또는 반려견과 관계가 없는 회원은 체중을 기록할 수 없다.
- 체중은 kg 단위이며 `0.1` 이상 `999.9` 이하로 입력한다.
- 체중은 소수점 한 자리까지만 입력할 수 있다.
- 정수 체중 입력은 허용하며, 저장 시 소수점 한 자리로 정규화한다. 예: `4`는 `4.0`으로 저장한다.
- 측정 시각은 사용자가 직접 입력한다.
- 측정 시각은 반려견 생년월일 당일 `00:00` 이후여야 한다.
- 측정 시각은 현재 한국 시간보다 미래일 수 없다.
- 동일한 측정 시각의 체중 기록은 허용한다.
- 체중 기록 요청마다 기존 이력을 수정하지 않고 새 `PetWeight` row를 생성한다.
- 현재 체중은 가장 최근 `measuredAt`의 기록으로 판단하며, 같은 시각이면 가장 큰 `id`를 가진 기록을 사용한다.
- 시간 값은 서비스 시간 기준인 `Asia/Seoul`의 `LocalDateTime`으로 처리한다.

## 흐름

1. 인증된 회원이 반려견 식별자, 체중, 측정 시각을 입력한다.
2. 시스템은 체중과 측정 시각의 필수값 및 형식을 검증한다.
3. 시스템은 반려견이 존재하고 삭제되지 않았는지 확인한다.
4. 시스템은 요청 회원이 반려견의 `OWNER` 또는 `FAMILY` 역할을 가진 `ACTIVE` 멤버십 회원인지 확인한다.
5. 시스템은 체중 범위와 소수점 자리 수를 검증한다.
6. 시스템은 측정 시각이 반려견 생년월일 이후이며 현재 한국 시간보다 미래가 아닌지 확인한다.
7. 시스템은 새 `PetWeight` 이력을 저장한다.
8. 시스템은 생성된 체중 이력 정보를 응답한다.

## 완료 기준

- [ ] 인증되지 않은 사용자는 체중을 기록할 수 없다.
- [ ] 존재하지 않거나 삭제된 반려견에는 체중을 기록할 수 없다.
- [ ] 반려견과 관계가 없거나 `LEFT` 상태인 회원은 체중을 기록할 수 없다.
- [ ] `ACTIVE` 상태의 `OWNER`, `FAMILY` 회원은 체중을 기록할 수 있다.
- [ ] 체중 또는 측정 시각이 누락되면 기록에 실패한다.
- [ ] 체중이 `0.1` 미만 또는 `999.9` 초과이면 기록에 실패한다.
- [ ] 체중의 소수점 자리가 한 자리를 초과하면 기록에 실패한다.
- [ ] 정수 체중 입력은 소수점 한 자리로 저장된다.
- [ ] 측정 시각 형식이 올바르지 않으면 기록에 실패한다.
- [ ] 측정 시각이 반려견 생년월일 당일 `00:00` 이전이면 기록에 실패한다.
- [ ] 측정 시각이 현재 한국 시간보다 미래이면 기록에 실패한다.
- [ ] 정상 요청마다 새 `PetWeight` 이력이 생성된다.
- [ ] 같은 측정 시각으로 여러 번 기록해도 각각의 이력이 생성된다.
- [ ] 성공 응답은 체중 이력 식별자, 체중, 측정 시각, 등록 시각을 포함한다.
- [ ] 성공 응답의 HTTP 상태 코드는 `200 OK`다.

## 예외

- 필수값 누락 또는 입력값 형식 오류
- 체중 범위 또는 소수점 자리 수 정책 위반
- 반려견 없음 또는 삭제된 반려견
- 반려견 멤버십 없음 또는 비활성 멤버십
- 반려견 생년월일 이전 또는 미래 측정 시각

## 테스트 기준

- `OWNER` 회원 체중 기록 성공
- `FAMILY` 회원 체중 기록 성공
- 미인증 사용자 기록 실패
- 관계 없는 회원 또는 `LEFT` 멤버십 회원 기록 실패
- 존재하지 않거나 삭제된 반려견 기록 실패
- 체중 필수값 누락, 범위 위반, 소수점 두 자리 입력 실패
- 정수 체중 입력 시 소수점 한 자리 저장 확인
- 측정 시각 필수값 누락 및 형식 오류 실패
- 반려견 생년월일 이전 측정 시각 실패
- 미래 측정 시각 실패
- 동일 측정 시각의 체중 기록 다건 생성 확인
- 성공 응답 필드와 `200 OK` 확인
