# REQ-009: 활성 견종 목록 조회

- **목표:** 사용자는 반려견 등록에 사용할 활성 견종 목록을 조회할 수 있다.
- **행위자:** 사용자
- **범위:** 활성 상태 견종 기준 데이터 조회
- **관련 엔티티:** `Breed`
- **제외 범위:**
  - 견종 등록, 수정, 비활성화 관리
  - 비활성 견종 조회
  - 견종 직접 입력
  - 페이지네이션 및 검색

## API

- `GET /api/v1/breeds`
- 인증: 불필요
- 성공 상태 코드: `200 OK`
- 페이지네이션: 미적용

## 응답값

응답은 활성 견종 목록 배열로 제공한다.

- `id`: 견종 식별자
- `name`: 견종명

## 정책

- 인증 없이 누구나 활성 견종 목록을 조회할 수 있다.
- `active = true`인 견종만 조회한다.
- 목록은 견종명 오름차순으로 정렬한다.
- 페이지네이션과 검색 기능을 적용하지 않는다.
- 활성 견종이 없으면 `200 OK`와 빈 배열을 응답한다.
- 응답에는 `id`, `name`만 포함하며 `active`, 생성일시, 수정일시는 포함하지 않는다.

## 흐름

1. 사용자가 활성 견종 목록 조회를 요청한다.
2. 시스템은 활성 상태 견종만 조회한다.
3. 시스템은 견종명 오름차순으로 목록을 정렬한다.
4. 시스템은 견종 식별자와 견종명을 배열로 응답한다.

## 완료 기준

- [ ] 인증 없이 활성 견종 목록을 조회할 수 있다.
- [ ] 활성 상태 견종만 목록에 포함된다.
- [ ] 비활성 상태 견종은 목록에 포함되지 않는다.
- [ ] 목록은 견종명 오름차순으로 정렬된다.
- [ ] 활성 견종이 없으면 `200 OK`와 빈 배열을 응답한다.
- [ ] 응답은 `id`, `name`만 포함한다.
- [ ] 응답에 `active`, 생성일시, 수정일시는 포함되지 않는다.

## 테스트 기준

- 인증 없이 활성 견종 목록 조회 성공
- 활성 견종만 조회되는지 확인
- 비활성 견종 제외 확인
- 견종명 오름차순 정렬 확인
- 활성 견종이 없는 경우 빈 배열 응답 확인
- 응답 필드 범위 확인
